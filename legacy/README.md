# legacy 디렉터리 안내

이 디렉터리는 현재 실행 구조에 직접 참여하지 않는 과거 자료를 보관합니다.
운영 코드, 현재 테스트 도구, 현재 instructions 문서와 섞이지 않도록 별도 상위 폴더로 분리했습니다.

| 경로 | 설명 |
|---|---|
| `archive/` | 이전 임시 자료와 과거 샘플 파일입니다. |
| `study/` | 설계 과정에서 참고한 학습 자료, PDF, 실험 코드입니다. |
| `rtsp_v1/` | 이전 RTSP v1 문서와 요구사항 파일입니다. |

현재 실행 기준 문서는 `instructions/`를 사용하고, 현재 RTSP 문서는 `docs/rtsp.md`를 사용합니다.
