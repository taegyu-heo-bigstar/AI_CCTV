# Edge host 자동 감지 차후 구현점

현재 refactor 브랜치는 Edge node host를 자동 추정하지 않습니다. 실행자는 `.env`의
`AI_CCTV_EDGE_HOST`에 AI server가 접근할 수 있는 Raspberry Pi 유선 IP를 직접
입력해야 합니다.

## 보류한 자동 감지 후보

| 후보 | 설명 | 보류 이유 |
|---|---|---|
| SSH 세션 IP | `SSH_CONNECTION`의 서버 측 IP를 Edge node IP로 추정 | SSH 실행 방식에만 유효하고 예외 상황 설명이 필요함 |
| 네트워크 인터페이스 조회 | 지정 인터페이스의 IPv4 주소를 `ip` 명령으로 조회 | 인터페이스 이름이 환경마다 다르고 Linux 명령 의존성이 생김 |
| UDP 라우팅 추정 | 외부 주소로 UDP 소켓을 연결해 로컬 IP를 추정 | 네트워크 상태에 따라 결과가 달라지고 실패 경로가 길어짐 |
| hostname 해석 | 호스트 이름의 IPv4 후보를 조회 | mDNS/DNS 설정에 따라 잘못된 주소가 나올 수 있음 |
| localhost fallback | 자동 감지 실패 시 `127.0.0.1` 사용 | 실제 유선 연결에서는 잘못된 값을 출력할 가능성이 큼 |

## 재도입 기준

자동 감지는 다음 조건을 만족할 때 다시 구현합니다.

1. 실패 순서와 오류 메시지가 단순해야 합니다.
2. 사용자가 출력값을 신뢰할 수 있도록 감지 출처를 함께 표시해야 합니다.
3. 잘못된 자동 감지값보다 명시 설정값을 항상 우선해야 합니다.
4. `AI_CCTV_EDGE_HOST`가 없을 때 무조건 긴 fallback을 타지 않아야 합니다.
