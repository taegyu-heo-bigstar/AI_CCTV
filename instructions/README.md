# instructions 디렉터리 안내

`instructions` 디렉터리는 실행 코드가 아닌 프로젝트 설명성 산출물을 보관하는 위치입니다.

| 경로 | 설명 |
| --- | --- |
| `flow.md` | 현재 실행 흐름과 책임 경계를 설명합니다. |
| `structure.md` | 소스 파일별 클래스와 함수 목록을 정리합니다. |
| `change.md` | `develop` 브랜치 대비 구조 변경 사항을 설명합니다. |

과거 샘플, 학습 자료, 임시 archive 자료는 루트의 `legacy/` 디렉터리에 보관합니다.
